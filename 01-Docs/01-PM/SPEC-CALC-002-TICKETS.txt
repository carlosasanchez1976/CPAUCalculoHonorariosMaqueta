CONTEXTO:
Los rangos están definidos por coeficiente K (valorObra / valorK):
- Rango A: coefK < 0.5
- Rango B: 0.5 ≤ coefK < 5
- Rango C: 5 ≤ coefK < 25
- Rango D: coefK ≥ 25

Los límites en pesos se calculan como: Límite_Coef_K × Valor_K

UBICACIÓN: App/Backend/03-Vercel/lib/utils/calculos/tablasCoeficientes.js

IMPLEMENTACIÓN:

```javascript
/**
 * Calcula los límites en pesos de cada rango según el valor K vigente
 * 
 * @param {number} valorK - Índice CPAU actualizado (ej: 574.813.607)
 * @returns {Object} Objeto con límites inferior/superior por rango
 * 
 * @example
 * const limites = calcularLimitesRangos(574813607);
 * // {
 * //   rangoA: { inferior: 0, superior: 287406803.5 },
 * //   rangoB: { inferior: 287406803.5, superior: 2874068035 },
 * //   ...
 * // }
 */
export function calcularLimitesRangos(valorK) {
  if (!valorK || valorK <= 0) {
    throw new Error('valorK debe ser un número positivo mayor a 0');
  }
  
  return {
    rangoA: {
      inferior: 0,
      superior: 0.5 * valorK
    },
    rangoB: {
      inferior: 0.5 * valorK,
      superior: 5 * valorK
    },
    rangoC: {
      inferior: 5 * valorK,
      superior: 25 * valorK
    },
    rangoD: {
      inferior: 25 * valorK,
      superior: Number.MAX_SAFE_INTEGER  // Infinity práctica
    }
  };
}
```

```javascript
    const rangoFinal = determinarRango(coeficienteK);
    const rangosAfectados = calcularRangosAfectados(detalleHonorarios);
    const limitesRangos = calcularLimitesRangos(valorK);
    
    // Response con nueva estructura
    return res.status(200).json({
      success: true,
      data: {
        calculoId: generarId(),
        tipoCalculo: 'basico',
        fechaCalculo: new Date().toISOString(),
        resultado: {
          detalleHonorarios,
          totalHonorarios,
          metadata: {
            valorK,
            coeficienteK,           // ← NUEVO
            rangoFinal,             // ← NUEVO
            rangosAfectados,        // ← NUEVO
            numeroItems: detalleHonorarios.length,
            limitesRangos          // ← NUEVO
          }
        }
      }
    });
    
  } catch (error) {
    console.error('Error en cálculo progresivo:', error);
    return res.status(500).json({
      success: false,
      error: 'Error procesando cálculo de honorarios'
    });
  }
}
```
