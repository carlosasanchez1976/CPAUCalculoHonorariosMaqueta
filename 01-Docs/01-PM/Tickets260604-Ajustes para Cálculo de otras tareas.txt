TICKET-002: Capa intermedia de filtrado de tareas por rol (Testing)
--------------------------------------------------------------------------------
OBJETIVO:
Permitir que usuarios con rol específico (ej: admin) puedan visualizar y probar
tareas profesionales marcadas como "no vigentes" en la base de datos, sin modificar
los datos de la API.

ALCANCE:
- Crear constante TAREAS_A_VALID_POR_ROL para configurar excepciones por rol
- Implementar función filtrarTareasPorRol() como capa de presentación
- Integrar filtro en NuevoCalculoPage antes de renderizar cards
- Documentar claramente el propósito temporal de testing

ARCHIVOS CREADOS:
- src/utils/tareasHelper.js (nueva utility)

ARCHIVOS MODIFICADOS:
- src/utils/constants.js (añadida TAREAS_A_VALID_POR_ROL)
- src/pages/NuevoCalculoPage.jsx (integración del filtro)

LÓGICA IMPLEMENTADA:
1. Tareas con vigente=1 → Siempre visibles para todos los roles
2. Tareas con vigente=0 → Visibles solo si están en TAREAS_A_VALID_POR_ROL para ese rol
3. Rol "admin" puede ver: CONFAC y ARBI (aunque vigente=0 en API)
4. Otros roles solo ven tareas con vigente=1

CARACTERÍSTICAS:
- No modifica datos de API ni base de datos
- Capa de presentación temporal para testing
- Fácilmente removible cuando termine período de pruebas
- Documentación extensiva en código
