TICKET #4: Implementar mensaje de ayuda que desaparece al completar campos
ESTADO: ✅ COMPLETADO
PRIORIDAD: 🟢 BAJA
================================================================================
ARCHIVO: App/Frontend/src/components/wizard/steps/DatosObraBasico.jsx
LÍNEAS: Sección de superficie y costo

DESCRIPCIÓN:
Cliente solicita: "este texto desaparece cuando se completan los campos"

Implementar mensaje de ayuda/nota que aparece cuando los campos están
vacíos y desaparece cuando el usuario completa la información.

EJEMPLO DE IMPLEMENTACIÓN:

```jsx
const [camposCompletos, setCamposCompletos] = useState(false);

useEffect(() => {
  // Verificar si los campos principales están completos
  const completos = formData.superficieTotal && 
                    formData.valorMetro2 && 
                    formData.cotizDolar;
  setCamposCompletos(completos);
}, [formData.superficieTotal, formData.valorMetro2, formData.cotizDolar]);

// En el render:
{!camposCompletos && (
  <div className={styles.helperNote}>
    <p>
      NOTA: La superficie cubierta se computa al 100%, las demás 
      superficies semicubiertas incorporadas según la condición y los 
      valores específicos de la obra...
    </p>
  </div>
)}
```

ESTILOS:
```css
.helperNote {
  background: #fff3cd;
  border: 1px solid #ffc107;
  border-radius: 8px;
  padding: 12px 16px;
  margin-top: 16px;
  font-size: 0.875rem;
  color: #856404;
  animation: fadeIn 0.3s ease;
}

@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}
```

CRITERIOS DE ACEPTACIÓN:
✅ Mensaje visible cuando campos están vacíos
✅ Mensaje desaparece al completar los campos requeridos
✅ Animación suave de desaparición
✅ Mensaje claro y visible (fondo amarillo claro)
✅ Responsive: funciona en móvil

IMPACTO:
🟢 BAJO - Mejora UX pero no crítico
⏱️ Tiempo estimado: 20 minutos

RESOLUCIÓN:
✅ Agregado estado camposCompletos que verifica superficieTotal, valorMetro2 y cotizDolar
✅ Implementado useEffect que actualiza el estado cuando cambian los campos
✅ Mensaje de ayuda renderizado condicionalmente: {!camposCompletos && (...)}
✅ Estilos CSS agregados:
  - Fondo amarillo claro (#fff3cd) con borde amarillo (#ffc107)
  - Border-left de 4px para destacar
  - Font-size 0.875rem, color #856404 (amarillo oscuro)
  - Animación fadeIn (0.3s) con translateY para entrada suave
✅ Texto: "NOTA: La superficie cubierta se computa al 100%..."
✅ Mensaje desaparece instantáneamente al completar los 3 campos principales

DESCRIPCIÓN:
Cliente solicita: "cuando marcan una opción se pone el cuadradito azul"

Los checkboxes deben cambiar a un cuadrado azul (morado #5B2FE6) cuando
están seleccionados/marcados.

IMPLEMENTACIÓN:

Reemplazar checkboxes nativos con versión estilizada:

```css
/* Ocultar checkbox nativo */
.checkbox {
  appearance: none;
  -webkit-appearance: none;
  width: 20px;
  height: 20px;
  border: 2px solid var(--color-gray-300);
  border-radius: 4px;
  cursor: pointer;
  position: relative;
  transition: all 0.2s ease;
}

.checkbox:hover {
  border-color: #5B2FE6;
}

/* Estado checked - cuadrado azul/morado */
.checkbox:checked {
  background-color: #5B2FE6;
  border-color: #5B2FE6;
}

/* Checkmark (✓) blanco dentro del cuadrado azul */
.checkbox:checked::after {
  content: '✓';
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  color: white;
  font-size: 14px;
  font-weight: bold;
}

.checkbox:focus {
  outline: none;
  box-shadow: 0 0 0 3px rgba(91, 47, 230, 0.2);
}
```

ALTERNATIVA (sin símbolo ✓, solo cuadrado sólido):
```css
.checkbox:checked {
  background-color: #5B2FE6;
  border-color: #5B2FE6;
}
```

CRITERIOS DE ACEPTACIÓN:
✅ Checkbox desmarcado: borde gris, fondo blanco
✅ Checkbox marcado: fondo morado #5B2FE6
✅ Checkmark (✓) blanco visible cuando está marcado
✅ Hover muestra borde morado
✅ Focus con box-shadow sutil
✅ Tamaño consistente en todos los checkboxes
✅ Funciona en todos los checkboxes de la aplicación

✅ Checkboxes desmarcados: borde gris #B0B0B0, fondo blanco
✅ Checkboxes marcados: fondo morado #5B2FE6 sólido
