================================================================================
1. PROBLEMA DETECTADO
================================================================================

SÍNTOMA:
El footer con el número de página (1/3, 2/3, 3/3) aparece en la PÁGINA SIGUIENTE
en lugar de al final de cada página actual, como se evidencia en la captura de
pantalla adjunta.

CAUSA RAÍZ:
El footer tiene posicionamiento absoluto con `bottom: -30px`, lo que lo coloca
FUERA del contenedor `.page`. Cuando Puppeteer genera el PDF con saltos de página,
el footer queda "flotando" y se renderiza en la página siguiente.

CÓDIGO PROBLEMÁTICO:
```css
.page {
  position: relative;        /* ← Contenedor de referencia */
  width: 210mm;
  min-height: 297mm;         /* ← Altura mínima A4 */
  padding: 0;
  page-break-after: always;
}

.footer-num {
  position: absolute;
  bottom: -30px;             /* ← PROBLEMA: -30px saca el footer FUERA del .page */
  width: 100%;
  z-index: 1;
}
```

DIAGRAMA DEL PROBLEMA:
```
┌─────────────────────────────────────┐
│ .page (min-height: 297mm)           │
│                                     │
│  Contenido de la página             │
│  (header, tablas, resumen, etc.)    │
│                                     │
│                                     │
└─────────────────────────────────────┘ ← Fin del contenedor .page (altura 297mm)
  ↓ -30px                                ← Footer se renderiza AQUÍ (fuera del .page)
  [1/3]                                  ← Puppeteer lo coloca en la SIGUIENTE página
────────────────────────────────────────  ← Salto de página (page-break)
┌─────────────────────────────────────┐
│ .page (Página 2)                    │
│  [1/3] ← Aparece acá                │  ← PROBLEMA
│                                     │
```

================================================================================
2. ANÁLISIS TÉCNICO
================================================================================

2.1 ¿POR QUÉ PASA ESTO?
────────────────────────
- `.page` tiene `min-height: 297mm` (tamaño A4 exacto)
- El footer usa `position: absolute; bottom: -30px`
- En HTML/CSS normal, esto funcionaría porque el body puede expandirse
- PERO en Puppeteer con `page-break-after: always`, cada `.page` es una
  "caja cerrada" de 297mm
- Todo lo que esté FUERA de esos 297mm (como el -30px) se va a la siguiente página

2.2 ¿POR QUÉ `bottom: -30px`?
──────────────────────────────
Probablemente se usó para lograr que el footer quede "pegado" al borde inferior
de la hoja A4, pero esto NO funciona con el modelo de páginas de Puppeteer.

2.3 ALTURA DISPONIBLE REAL
───────────────────────────
Altura A4: 297mm
Márgenes Puppeteer (actual): top 15mm + bottom 15mm = 30mm
Altura disponible para contenido: 297mm - 30mm = 267mm

Si el contenido + footer exceden 267mm, habrá overflow a la página siguiente.

3. SOLUCIONES PROPUESTAS
================================================================================

────────────────────────────────────────────────────────────────────────────────
SOLUCIÓN A: Solo Template HTML/CSS (RECOMENDADA - Sin tocar backend)
────────────────────────────────────────────────────────────────────────────────

VENTAJAS:
✅ No requiere modificar el backend (pdfService.js)
✅ Mantiene el enfoque de plantilla hardcodeada (Fase 1)
✅ Funciona con la configuración actual de Puppeteer
✅ Control visual directo en el template

DESVENTAJAS:
⚠️ El footer es parte del contenido, no un "footer real" de PDF
⚠️ Si el contenido es muy largo, el footer podría quedar en página siguiente
⚠️ Hay que calcular manualmente el espacio disponible

IMPLEMENTACIÓN:
───────────────

CAMBIO 1: Ajustar CSS del .page para usar flexbox
```css
.page {
  position: relative;
  width: 210mm;
  min-height: 267mm;          /* ← Cambiar de 297mm a 267mm (resta márgenes) */
  padding: 15mm 12mm 0 12mm;  /* ← Agregar padding top/sides, NO bottom */
  page-break-after: always;
  page-break-inside: avoid;
  background: var(--text-white-color);
  
  /* Flexbox para controlar layout interno */
  display: flex;
  flex-direction: column;
}
```

CAMBIO 2: Wrapper para contenido principal
```css
.page-content {
  flex: 1;                    /* ← Ocupa todo el espacio disponible */
  min-height: 0;              /* ← Permite que flex funcione correctamente */
}
```

CAMBIO 3: Footer fijo al final (DENTRO del .page)
```css
.footer-num {
  position: relative;         /* ← Cambiar de absolute a relative */
  bottom: 0;                  /* ← Mantener en 0 (ya no -30px) */
  width: 100%;
  margin-top: auto;           /* ← Empuja el footer al final del espacio flex */
  padding-bottom: 10mm;       /* ← Separación del borde inferior */
  z-index: 1;
}
```

CAMBIOS EN HTML:
Envolver el contenido de cada página:
```html
<div class="page">
  <div class="page-content">
    <!-- Header, tablas, resumen, todo el contenido -->
  </div>
  
  <!-- Footer (FUERA del .page-content pero DENTRO del .page) -->
  <div class="footer-num">
    <div class="footer-content-num">
      <div class="footer-linea"></div>
      <div class="footer-texto">
        <span>1/3</span>
      </div>
    </div>
  </div>
</div>
```

────────────────────────────────────────────────────────────────────────────────
NOTAS TÉCNICAS
────────────────────────────────────────────────────────────────────────────────

1. **displayHeaderFooter: true**
   - Activa el sistema de header/footer de Chromium
   - Renderiza en el área de MARGEN (fuera del contenido HTML)
   - NO cuenta como parte del contenido de la página

2. **pageNumber y totalPages**
   - Son variables especiales de Chromium
   - Se reemplazan automáticamente en cada página
   - NO requieren JavaScript ni Handlebars

3. **Estilos del footerTemplate**
   - SOLO acepta CSS inline (no clases externas)
   - El width: 100% es relativo al ancho de la página (210mm - márgenes)
   - padding-right: 12mm alinea el texto con el margen derecho del contenido

4. **Margen bottom aumentado**
   - De 15mm a 20mm para dar espacio vertical al footer
   - El footer se renderiza DENTRO de esos 20mm
   - El contenido HTML termina 20mm antes del borde inferior

5. **Border-top**
   - La línea horizontal que aparece en el diseño actual
   - 1px solid #6b6b6b (color gris del diseño)
